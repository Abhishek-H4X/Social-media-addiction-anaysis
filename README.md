Addiction Score Analysis Dashboard
📌 Project Overview

This project focuses on analyzing addiction score data using Power BI. The dashboard provides interactive visualizations and insights into addiction patterns, helping users understand trends, demographic distributions, and key factors influencing addiction scores.

🎯 Objectives
Analyze addiction score data effectively.
Identify trends and patterns in addiction behavior.
Compare addiction scores across different categories.
Create interactive dashboards for better decision-making.
Present data-driven insights through visualizations.
🛠️ Tools & Technologies Used
Power BI – Data visualization and dashboard creation.
Power Query – Data cleaning and transformation.
DAX (Data Analysis Expressions) – Calculated measures and KPIs.
Microsoft Excel / CSV Dataset – Data source.
📊 Dashboard Features
Interactive filters and slicers.
Addiction score distribution analysis.
Demographic-based comparisons.
Trend analysis and key performance indicators (KPIs).
Visual reports using charts, graphs, and cards.
📈 Key Insights
Identified patterns in addiction scores across different groups.
Highlighted categories with higher addiction tendencies.
Visualized score distributions and trends.
Enabled data-driven interpretation through interactive reports.
🔄 Data Processing Steps
Imported dataset into Power BI.
Cleaned and transformed data using Power Query.
Removed duplicates and handled missing values.
Created calculated columns and measures using DAX.
Designed interactive visualizations and dashboards.
Generated insights from the analyzed data.
